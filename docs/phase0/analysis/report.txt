Chosen: f_sys = 128 MHz (12 MHz x 128 = 1536 MHz VCO, POSTDIV1 = 6, POSTDIV2 = 2)
  wake-up (standard mode): 128 MHz / 64 = 2.000 MHz, clkdiv = 32, high = low = 32 sys cycles = 250.00 ns
  ultrasonic: 128 MHz / 40 = 3.200 MHz, clkdiv = 20, high = low = 20 sys cycles = 156.25 ns
  tach sampler: 3.2 MHz / 16 = 200 kHz, clkdiv = 640 (1 PIO cycle per sample)
  crystal error 30 ppm -> f_pdm error 96 Hz (still inside 3.072-4.8 MHz)
  crystal error 50 ppm -> f_pdm error 160 Hz (still inside 3.072-4.8 MHz)
  half period 156.25 ns; PIO samples the pin 15.62 ns before the rising edge
  setup margin = 156.25 - 15.62 - tDD(max) 40 = 100.6 ns
  hold margin  = 15.62 + tDZ(min) 3 = 18.6 ns (pad and cable delay not included)

==============================================================================

A: /16 -> 200 kHz (alias-free to 80 kHz)
  taps 259 at 3.2 MHz = 17 multiplies per output sample; group delay 40.3 us; span 81 us
  gain at 1/20/23/25/40 kHz: +0.0000 dB, +0.0000 dB, +0.0000 dB, +0.0001 dB, +0.0000 dB
  worst stopband gain from 120 kHz up: -98.7 dB
  first alias band into 0-40 kHz starts at 160 kHz (gain there -112.6 dB)
  step-response overshoot: 7.8 %

B: /32 -> 100 kHz (alias-free to 40 kHz)
  taps 1027 at 3.2 MHz = 33 multiplies per output sample; group delay 160.3 us; span 321 us
  gain at 1/20/23/25/40 kHz: +0.0000 dB, +0.0000 dB, -0.0000 dB, +0.0000 dB, -0.0001 dB
  worst stopband gain from 60 kHz up: -99.7 dB
  first alias band into 0-40 kHz starts at 60 kHz (gain there -99.7 dB)
  step-response overshoot: 8.8 %

Alias bound that does not depend on the mic's modulator: a 1-bit stream has total power
0 dBFS, so everything folded back is below the stopband gain (about -100 dBFS).
Mic noise floor (A-weighted, audio band): -26 dBFS - 64.3 dB = -90.3 dBFS.
